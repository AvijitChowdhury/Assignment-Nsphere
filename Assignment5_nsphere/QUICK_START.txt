⚙️ PARAMETER MEANINGS
======================
./nsphere <ndim> <radius> [threads_per_block] [skipcpu]

  ndim              = Dimension (D)
  radius            = Radius (R)
  threads_per_block = GPU threads (default 256, try 512, 1024)
  skipcpu           = Skip CPU check (1=skip for large problems)

EXAMPLES:
  ./nsphere 7 8.0              # D=7, R=8.0, default settings
  ./nsphere 7 8.0 256          # Explicitly set 256 threads
  ./nsphere 7 8.0 256 1        # Skip CPU check (for large problems)

🔧 TROUBLESHOOTING
===================

Q: nvcc: command not found
A: module load cuda

Q: CUDA error: no kernel image for architecture
A: Edit makefile, change -arch=sm_75 to match your GPU
   nvidia-smi --query-gpu=name,compute_cap --format=csv

Q: Make: Nothing to be done for 'all'
A: make clean && make

Q: nsphere binary not found
A: make clean && make

Q: Wrong count / MISMATCH
A: Recompile and check both CPU and GPU run same inputs

Q: GPU memory error / CUDA out of memory
A: Reduce D or R - the problem is too large

Q: Timeout on SLURM
A: Increase --time in .sh file, or reduce D/R
